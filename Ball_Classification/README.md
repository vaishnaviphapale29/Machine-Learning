# Ball Classification using Decision Tree

My first Machine Learning project using Python and Scikit-learn.

## Description

This project classifies a ball as a **Tennis Ball** or **Cricket Ball** using a Decision Tree Classifier.

The dataset is manually created using:
- Weight of the ball
- Surface of the ball

**Surface:** Rough = 1, Smooth = 0  
**Target:** Tennis = 1, Cricket = 2

## Algorithm

**Decision Tree Classification**

## Technologies

- Python
- Scikit-learn

## Working

1. Create the dataset manually.
2. Split the data into training and testing sets.
3. Train the Decision Tree model.
4. Give new ball features to the model.
5. Predict the type of ball.
